🏦 Insurance Data Analysis Dashboard

 📌 Project Overview

This project focuses on analyzing insurance data and creating an interactive dashboard using Power BI to gain insights into customer and policy information.

 🎯 Objectives

- Analyze insurance-related data
- Create interactive Power BI dashboards
- Identify important trends and patterns
- Generate business insights

 🛠️ Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis
- Excel / CSV Dataset

 📈 Dashboard Features

- KPI Cards
- Interactive Charts
- Filters and Slicers
- Category-wise Analysis
- Trend Analysis

 📂 Project File

- `Insurance Data.pbix`
